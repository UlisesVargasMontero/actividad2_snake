# Descripción
El juego trata de hacer que una serpiente coma manzanas para que crezca, pero debe evitar comerse a si misma o chocar con las paredes.

# Cómo se usa
Movimiento:
- up: movimiento hacia arriba
- down: movimiento hacia abajo
- left: movimiento hacia la izquierda
- right: movimiento hacia la derecha
